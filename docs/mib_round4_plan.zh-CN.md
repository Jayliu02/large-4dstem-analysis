# MIB 第四轮计划：真实背景注入回收与可执行复核

承接第三轮提交 `be119aa`。用户已确认暂无标定；前三轮数据不变。第四轮不再调节检测器，而是在真实背景上测试弱峰回收，并把人工复核从空白 CSV 推进为可操作、可导入和可审计的流程。

## 运行前固定的范围

1. 核验第三轮及前置产物。锁定第三轮已选 `raw / relative=0.01 / SNR=5` 检测器、原点模型与全部质量规则。
2. 使用第三轮的 72 张已固定复核 DP，不称它们为新的独立验收集；不根据本轮结果反向调整参数。
3. 每张 DP 选择一个远离现有候选的位置，以及一个距离已接受非中央峰 10 px 的拥挤位置。每个位置测试两种已知形状：实测中央束的正峰模板和窄 Gaussian；峰顶期望增量为 8/16/32 counts。分别注入，每张图只加一个目标。
4. 以新增 Poisson 计数模拟信号，记录精确位置、形状、幅度、随机种子、总期望计数、是否原图已有近邻峰、回收判定与定位误差。零注入原图作为同位置对照；原图已命中的位置不作为新增回收成功。
5. 一对一 2 px 位置匹配；按 ROI/形状/强度/拥挤程度分层报告。强注入（32 counts）的孤立位置回收率目标 ≥90%，作为诊断阈值，失败也保留全部结果。经验注入不代表真实样品全部峰形，不将回收率当作实测 precision/recall 或物相可信度。

## 人工复核交付

生成独立离线 HTML：显示 72 张原始 DP、第三轮峰位置、半计数支持标记、局部指标；支持 log/linear、逐峰 valid/false_peak/uncertain 标记、Shift+点击添加主要漏峰、逐 DP 完成标记、浏览器本地草稿及 JSON 导出。

复核 JSON 绑定本轮 `bundle_id` 和固定 DP/峰标识，导入时拒绝错误来源、未知或重复 ID、缺失峰、越界漏峰坐标、不完整的完成标记。记录填写者及声明的时间，不假造专家身份或自动填充结论。

预设复核接受规则：每 ROI 至少 20 张完整复核 DP；所有标记已处理、无 uncertain；假峰占已标记检出峰的比例 ≤5%；每张完整 DP 的主要漏峰平均数 ≤0.5。完整但不合格的复核记为 failed，不改阈值。未填写记为 pending。此规则属于可追溯的工程复核流程，不替代标样和实验物理验证。

Gate 3 的放行还要求注入诊断阈值通过。无人工复核时不放行；无独立标定时 Gate 5 始终未通过，不运行相/取向/应变，也不自动扩展到全场。
