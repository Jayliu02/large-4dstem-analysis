# MIB 第三轮结果与复现

已执行 [第三轮计划](mib_round3_plan.zh-CN.md)：低阈值候选检测、局部质心细化、合成参数选择、全新实测复核集、三 ROI 完整峰提取及 P5 标定状态记录。输出为 `outputs/mib_round3`，前两轮产物哈希保持不变。

## 参数选择与合成验收

候选方法为原始峰、模板相关、两分支去重合并；候选相对强度阈值统一为 0.01，局部 SNR 候选为 5/8/12。用原始局部计数扣背景后迭代质心细化，并保留峰宽、细化位移、单像素贡献及全部拒绝候选。

24 张含峰合成图加 8 张背景/孤立亮点图用于调参，另一组随机种子的同规模数据用于验收。模拟含泊松噪声、中央弥散背景、变化宽度/强度、邻近峰及孤立亮点。按精确率至少 0.95 约束下的召回率选择，最终为 **原始峰低阈值检测＋局部细化，SNR ≥5**。合并分支没有在这组合成条件下胜出；参数在新实测位置分析前冻结。

独立合成验收 144 个已知峰全部匹配、无额外检出、纯背景假峰为 0；39 个弱峰全部匹配。定位误差中位数 0.1078 px、P95 0.4043 px、最大值 0.7237 px，通过预设 2 px 一对一匹配定义和 precision/recall 阈值。这仅是本组简化模拟条件下的结果，不能声称实测准确率为 100%。

## 实测结果

每个 ROI 新取 24 个分层复核位置，排除前两轮的已存抽样、调参、复核、初查和模板来源点。比较基线是第二轮固定参数的模板分支，使用同一批新位置重算。低阈值方案还对全部 3×1,024 个位置执行了完整检测。

| ROI | 接受峰数（含中央束） | 中央束中位/P95误差 px | 新位置基线/本轮峰数 | 新增峰两半均支持/新增峰 |
|---|---:|---:|---:|---:|
| grain | 14,948 | 0.0564 / 0.0934 | 111 / 344 | 179 / 233 |
| boundary | 16,737 | 0.0586 / 0.1121 | 126 / 400 | 203 / 274 |
| texture | 12,317 | 0.0702 / 0.2436 | 138 / 290 | 124 / 152 |

三个 ROI 合计 **44,002 个质量规则通过的峰**。72 个新复核位置相较模板基线新增 659 个峰，基线峰在 2 px 一对一匹配定义下未丢失。新增峰有 **506/659（76.8%）** 在两份半计数数据中均能检出；这一比例是稳定性指标，不是假峰率或正确率。

拆分通过对每个像素计数作二项抽样得到，两份计数逐像素之和等于原始 DP。它是同一次采集的条件重采样，并非独立重复实验；半剂量仍用相同 SNR 门槛，弱峰消失可能仅因剂量降低，复现的背景结构也不能据此认定为真实反射。此指标没有用于筛除全剂量峰。

三 ROI 中央束覆盖率均为 100%，均通过工程阈值；每个 ROI 独立重读具有非零偏移的 8×8 子块，候选数、接受判定一致，原始及相对坐标最大差均为 0 px。实测每 DP 最大初始候选数分别为 48/60/66，未触及继承的 70 峰上限。

独立叠加图抽查显示，以前遗漏的部分弱斑已补出，同时中央束保持稳定；最弱斑和结构化背景仍需逐点核验。领域复核未完成，Gate 3 未自动放行，所有实验峰表继续标记为 **provisional**。

## 复现与校验

```powershell
./.conda-phase/python.exe scripts/05_mib_round3.py
./.conda-phase/python.exe scripts/05_mib_round3.py --verify
./.conda-phase/python.exe -m pytest tests/test_mib_round1.py tests/test_mib_round2.py tests/test_mib_round3.py -q -p no:cacheprovider
```

16 项测试通过，覆盖原点、坐标、模板、唯一匹配、合并分支来源、质心细化、孤立亮点拒绝、去重、计数拆分守恒和拒绝未经验证的物理尺度。真实产物检查通过，包括前两轮不变、复核集合无交集、合并峰表与 ROI 一致、相对坐标正确及未标定状态。

`--config` 指定配置，`--output` 使用新输出目录；配置改变或已有人工复核标注时禁止覆盖原运行。`status.json` 区分运行中、失败与完成。只按 DP/ROI 读取原始 MIB，不物化全场 4D 数据。

主要产物：

- `selected_parameters.json`、`synthetic_qc.json`：冻结参数和合成训练/验收结果。
- `P3_P4/sampling_*.npz`：新复核位置及排除集合。
- `P3_P4/holdout_*.png`、`holdout_metrics_*.csv`、`split_candidates_*.npz`：新位置对照和半计数诊断。
- `P3_P4/candidates_*.npz`：全部原始候选、细化坐标和拒绝原因。
- `P3_P4/peaks_corrected_*.npz`、`merged_peaks.npz`：通过质量规则的峰及像素坐标。
- `P3_P4/coordinates_spec.md`、`qc_summary.json`：字段契约及工程指标。
- `P3_P4/review_*.csv`：待领域人员填写假峰、主要漏峰及 verdict；未自动生成专家结论。
- `run_manifest.json`、`report_zh.md`：来源、产物哈希及本次机器报告。
