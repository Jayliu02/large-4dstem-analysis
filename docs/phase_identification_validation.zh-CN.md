## 合成验证

执行：

```powershell
python scripts/validate_phase_identification.py --calibration
```

采用偏离模板网格 0.4° 的独立区轴、随机平面内角度与束心位置，在 `0.009 / 0.015 / 0.025 Å⁻¹/像素` 下生成控制图样。退化控制加入 0.35 像素噪声、15% 随机缺失斑点和两个离群点。

- 135 个纯相／退化控制图样中，初筛接受 90 个，没有错误的已接受标签，其余被拒绝。
- 135 个随机角度控制全部被拒绝。
- 135 个几何混合图样中，132 个被拒绝，仍有 3 个通过初筛，说明该方法不能证明单相纯度。
- 已知尺度 `0.015` 被恢复为 `0.01495165 Å⁻¹/像素`，相对误差约 0.32%，128 个留出图样全部支持该尺度。

上述初筛统计在随机对照阈值和束心／尺度扰动门槛之前计算。合成控制仍使用同一运动学正向模型，不能代替实测材料真值，也不描述动态衍射。完整数值见 `synthetic_validation.json` 和 `synthetic_calibration/`。

## 解释边界

用户提供的 `Ti-hcp.cif` 经原子结构与对称性检查对应 ω-Ti；真实 α-hcp 候选来自 COD 9008517。相识别功能和全扫描处理已完成，但当前实测数据未得到可靠相结论。继续确定实际相分布，需要优先补充独立倒空间标定及实际加速电压，再检查模板覆盖、强弱反射筛选和重叠晶粒的影响。
